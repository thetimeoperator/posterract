# Posterract creative project

- The canvas and timeline are generated from the local TSX source.
- Keep one top-level scene per independently exportable video.
- Preserve stable element ids when editing existing elements.
- Do not place credentials or social-network tokens in this folder.
- Read .posterract/docs before using an unfamiliar SDK primitive.
- For diagrams, read .posterract/docs/diagrams.md, choose the visual design from the user's meaning, and inspect captures before claiming success.
- Run posterract doctor --json before beginning local agent work.
- Run posterract context --json --tree to inspect the active project and runtime.
- Run posterract validate and posterract check after every meaningful edit.
- Inspect posterract capture output before claiming a visual result is correct.
- Export, post, or schedule only after the user explicitly asks.
