# Posterract Composition SDK 0.201

This directory is the version-matched authoring reference copied into each project. The local project documentation is authoritative for that project.

Start with [module-contract.md](module-contract.md), [elements.md](elements.md), [diagrams.md](diagrams.md), [timing.md](timing.md), and [inspector-variables.md](inspector-variables.md).

One `<stage>` is a project workspace. Each top-level `<scene>` is one independently exportable video. Nested `<sequence>` elements organize timed sections inside that video.
