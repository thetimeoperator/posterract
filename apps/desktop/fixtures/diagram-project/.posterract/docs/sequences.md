# Sequences

`<sequence>` groups timed children into a chapter or track section. Use it for A-roll, B-roll, captions, overlays, audio beds, or reusable blocks. Sequence timing is resolved inside the parent window and appears as a collapsible timeline row.

Children still keep stable IDs. Moving a clip between sequences is a source-backed tree move; moving it between scenes is explicit and converts its time coordinates.
