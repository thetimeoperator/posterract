# Diagram explainer

For a request such as “show how a recommendation engine turns behavior into ranked content”:

- Build a left-to-right flow with semantic node IDs.
- Use arrows whose labels explain the transformation, not merely “next”.
- Add a feedback arrow for new behavior.
- Use an equation or plot only when it clarifies the logic.
- Reveal one causal step at a time, then hold the complete system.
- Capture each reveal and the final state before reporting success.

Use the exact supported element props from `.posterract/docs/diagrams.md`.
